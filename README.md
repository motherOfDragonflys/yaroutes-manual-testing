# Ручное тестирование сервиса «ЯМаршруты» (поездка на своём автомобиле)

Ручное тестирование формы расчёта времени и стоимости поездки на собственном автомобиле:
полный цикл — от тест-анализа требований до баг-репортов и итогов прогона.

**Роль:** ручной тестировщик
**Стек:** Google Sheets, классы эквивалентности и граничные значения, тест-кейсы, баг-репорты

## Структура проекта

| Документ | Содержание |
|---|---|
| [Этап 1. Тест-анализ](docs/01-test-analysis.md) | Декомпозиция полей формы: часы, минуты, адреса «Откуда»/«Куда», интервалы времени, расчёт |
| [Этап 2. КЭ и ГЗ](docs/02-classes-and-boundaries.md) | Классы эквивалентности и граничные значения для всех полей, тестовые данные |
| [Этап 3. Тест-кейсы](docs/03-test-cases.md) | 67 кейсов с шагами, ожидаемым результатом, окружением и трассировкой на дефекты |
| [Этап 4. Баг-репорты](docs/04-bug-reports.md) | 16 дефектов с шагами воспроизведения и фактическим результатом |
| [Этап 5. Итоги](docs/05-summary.md) | Сводка прогона, покрытие дефектов, вывод по релизу |

Исходная таблица целиком: [Google Sheets](https://docs.google.com/spreadsheets/d/1vJrl1nrgt5S5qXMDpz8wvPdOAMvr5Pt3-6KoPyf1wpU/edit?gid=1610041137#gid=1610041137)

## Ключевые результаты

- **67 тест-кейсов**: 41 Passed / 26 Failed
- **16 баг-репортов**: 2 блокирующих, 5 средних, 9 низких
- **Блокирующие дефекты**: некорректный расчёт времени в пути (7 мин. → отображается 4 мин.)
  и стоимости (52 руб. → 34 руб.) при расстоянии больше 0 км — функция расчёта не может быть выпущена
- Валидация диапазонов и форматов работает; провалены отдельные граничные значения (24 в «Часах»),
  пустые поля (валидация не срабатывает) и автодополнение нуля перед однозначным числом
