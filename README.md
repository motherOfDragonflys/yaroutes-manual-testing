# Тестирование сервиса «ЯМаршруты» (поездка на своём автомобиле)

Ручное тестирование формы расчёта времени и стоимости поездки на собственном
автомобиле: от тест-анализа требований до баг-репортов и итогов прогона.

**Стек:** чек-листы и тест-кейсы в Google Sheets, классы эквивалентности,
граничные значения. Роль — ручной тестировщик.

## Что в проекте

Полная документация — [Google Sheets](https://docs.google.com/spreadsheets/d/1vJrl1nrgt5S5qXMDpz8wvPdOAMvr5Pt3-6KoPyf1wpU/edit?gid=1610041137#gid=1610041137):

| Этап | Содержание |
|---|---|
| 1. Тест-анализ | Декомпозиция полей формы: часы, минуты, адреса «Откуда»/«Куда», интервалы времени начала поездки |
| 2. КЭ и ГЗ | Классы эквивалентности и граничные значения для всех полей, тестовые данные |
| 3. Тест-кейсы | 67 кейсов с предусловиями, шагами, ОР, окружением и трассировкой на баги |
| 4. Баг-репорты | 16 дефектов: 2 блокирующих, 5 средних, 9 низких |
| 5. Итоги | Сводка прогона и вывод по релизу |

## Ключевые результаты

- **67 тест-кейсов**: 42 Passed / 25 Failed
- **16 баг-репортов**, из них 2 блокирующих: некорректный расчёт времени и
  стоимости поездки (занижение времени с 7 до 4 мин, стоимости с 52 до 34 руб.)
- Блокирующие дефекты не позволяют выпускать расчёт; остальные правятся параллельно
